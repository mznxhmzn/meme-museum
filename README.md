# 表情包数字符号博物馆

网络专题网页设计作品：以博物馆展陈的形式，梳理网络情绪符号从 1982 年 ASCII 笑脸到 AI 生成面孔的演化。

在线预览：https://meme-museum-mzn.netlify.app

## 结构

1. **首屏**：一句话六个时代
2. **序厅**：六座白色展台，台面标年份（1982 / 1990s / 1999 / 2000s / 2010s / 2024）
3. **馆藏说明**：为什么按「面孔被生产的方式」分期
4. **展品目录**：横向年代轴（六个节点）+ 十件展品的合排栅格；点年代可筛选，点展品拉出「五问拆解」
5. **十张脸背后的三种流通机制**
6. **同一句，六种面孔**：一句话在六种视觉语言里的对照，每一格可跳到对应年代
7. **三个维度**：表达形式 / 表达能力 / 传播方式，各用一句话概括它往哪儿走
8. **征集与落款**

六个时期与展品的对应：

| 年代 | 时期 | 展品 |
| --- | --- | --- |
| 1982 | 文字字符期 | 笑脸符号 :-)（原帖）、ASCII 符号表 |
| 1990s | 颜文字期 | 颜文字 (^_^) |
| 1999 | 绘文字期 | i-mode 绘文字 |
| 2000s | 平台表情期 | 平台自带表情（2003 / 2007 / 2011 三代） |
| 2010s | 网络表情包期 | 熊猫头、乖巧宝宝、女人骂猫 |
| 2024 | AI 生成期 | 黏土滤镜、AI 生成表情包 |

合排规则：`6+3+3 / 4+4+4 / 3+3+3+3`（12 栏），筛选后自动切成两栏或单栏。

## 文件

- `index.html`：结构 + 内联样式 + 内联脚本（含内嵌的标题字体子集，约 135 KB）
- `assets/`：十件展品的图源与 `图源清单.md`
- `exhibits/`、`icons/`：页面衍生素材
- `netlify.toml`：发布配置

## 说明

- **字体**：标题用的 Noto Serif SC 900 只取页面实际用到的 112 个汉字，子集化后以 `@font-face` 内嵌（22 KB woff2），不再依赖访客本机是否装了这个字体。
- **图片**：走 `assets/` 外部引用，不再 base64 内嵌——浏览器能缓存、能懒加载，部署时必须连 `assets/` 一起上传。
- **可读性**：卡片正文 14px、抽屉正文 15px（面板 460px）、注释类小字最低 10–11px、页脚对比度提到 5:1。
- 展品图像版权归原作者，页面仅作教学展示使用。熊猫头一张已裁去商城横幅。
